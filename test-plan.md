# Test Plan: Begah Homes v0.1.2

## Phases
| Phase | Coverage |
|---|---|
| 0 | Setup: device, install, test log, bug template |
| 1 | Install, launch, permissions, first-run behavior |
| 2 | Onboarding, sign-up, login, logout, password reset |
| 3 | Core features: browsing, search, filters, listing details, favorites, contact/booking |
| 4 | Forms and input validation |
| 5 | Navigation: back button, rotation, backgrounding, app kill, deep links |
| 6 | Network: offline, slow connection, connection switching |
| 7 | UI and accessibility: screen sizes, font scaling, dark mode |
| 8 | Performance: startup, scrolling, memory, battery, app size |
| 9 | Security basics: permissions, stored data, HTTPS |
| 10 | Regression and final sign-off |

## Severity Guide
- **Critical:** crash, data loss, security hole, or a core feature fully blocked
- **High:** major feature broken, with no workaround
- **Medium:** a feature works incorrectly, but there is a workaround
- **Low:** cosmetic issues, typos, minor layout problems
